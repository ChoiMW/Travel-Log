## ✨ 주요 핵심 기능

1. **🗺️ 2단계 계층형 18배 슈퍼 줌 지도 (Hierarchical LOD Map)**
   - 전국 줌아웃 시에는 **17개 광역시·도 대표 캡슐(`경기도 (42곳)`, `강원도 (18곳)`)**로 깔끔하게 표시.
   - 클릭 및 줌인 시 **250개 세부 시·군·구가 선명하게 분할 렌더링**되어 글자 겹침을 100% 원천 차단.
   - 천안, 청주, 전주, 수원 등 복합 행정시 **원클릭 3.8x 드릴다운 줌**.

2. **📸 사진 EXIF 메타데이터 기반 자동 지오코딩 (Zero-Friction)**
   - 사진 파일을 드래그&드롭하면 촬영 일시와 GPS 위경도를 자동 추출하여 0.01초 내에 방문 시군구 자동 매핑.

3. **📍 실시간 GPS & 오늘 날짜 기반 여행 자동 매칭 (Strict Match)**
   - 현재 머무르고 있는 위치(GPS)와 오늘 날짜를 감지하여 진행 중인 여행을 상단 라이브 배너로 즉시 안내 및 포켓 자동 선택.

4. **🧳 여행 전주기 올인원 스마트 포켓 (1:1 귀속 관리)**
   - **일정표 (Itinerary)**: Day-by-Day 일자별 시간순 방문 장소 관리 & 네이버 지도 길찾기 1초 연동.
   - **티켓/QR 월렛**: 모바일 승차권/입장권 예약번호 및 현장 전용 고대비 풀스크린 QR 뷰어.
   - **짐싸기 체크리스트**: 카테고리별 준비물 체크 및 실시간 달성률 프로그레스 바.
   - **1/N 가계부**: 지출 내역 관리 및 동행자 인원수별 1인당 정산 금액 자동 계산.

5. **📊 AI 여행 DNA 페르소나 리포트 & 통계**
   - 방문 지역과 테마 태그를 분석하여 `🍲 로컬 미식 탐험가`, `🌲 피톤치드 힐링 러버`, `🚗 로드트립 어드벤처러`, `✨ 낭만 여행자` 성향 카드 제공.
   - 사계절(봄/여름/가을/겨울) 여행 분포 및 17개 시도별 세부 정복 통계.

6. **📱 3종 소셜 공유 맵 카드 생성기 (Canvas Exporter)**
   - `[인스타 스토리 (9:16)]`, `[토스 미니멀 (1:1)]`, `[여권 국토정복 증명서]` 고화질 PNG 즉시 다운로드.

7. **🔒 100% 온디바이스(Zero-Server) 프라이빗 보안**
   - 모든 사진과 기록은 브라우저 내부 **IndexedDB**에만 저장되며 외부 서버로 일절 전송되지 않음.
   - 원클릭 JSON 무손실 백업 및 복원 지원.

## 🚀 로컬 실행 방법

```bash
# 의존성 패키지 설치
npm install

# 로컬 개발 서버 실행 (포트 3000)
npm run dev

# 프로덕션 번들 빌드 검증
npm run build
```
